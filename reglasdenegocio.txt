

# REGLAS DE NEGOCIO - SISTEMA DE FINANZAS PERSONALES

## 1. AUTENTICACIÓN Y USUARIOS

| ID | Regla | Implementación |
|----|-------|----------------|
| **RN-001** | El usuario debe registrarse con email válido y contraseña (mínimo 8 caracteres) | `signUp()` en `FinanceApiService` |
| **RN-002** | El login genera Access Token y Refresh Token | `signIn()` llama a `SupabaseAuthClient` |
| **RN-003** | El token puede ser renovado mediante refresh token | `refresh()` en controller |
| **RN-004** | El cierre de sesión invalida el refresh token | `signOut()` en controller |
| **RN-005** | Cada usuario tiene un perfil único con configuración personalizada | `profiles` table |

## 20. FLUJOS ESPECIALES

| ID | Regla | Flujo |
|----|-------|-------|
| **RN-092** | Pago de partialidad | Seleccionar origen → Crear gasto → Reducir deuda → Reducir tarjeta (si aplica) |
| **RN-093** | Retiro de efectivo | Seleccionar débito origen → Restar de débito → Sumar a efectivo |
| **RN-094** | Aporte a meta | Seleccionar origen → Crear gasto → Actualizar progreso |
| **RN-095** | Compra a meses | Seleccionar tarjeta → Crear deuda → Crear N partialidades → NO actualizar saldo tarjeta |

---

## DIAGRAMA DE ESTADOS

```
Deuda: Activa (remaining_balance > 0) → Pagos → Saldada (remaining_balance ≤ 0)
Partialidad: Pendiente (paid = false) → Pagar → Pagada (paid = true)
Meta: Activa → Agregar progreso → Alcanzada (progress = target)
Pago recurrente: Activo → Pagar ahora → Actualiza next_due_date
```

## Flujo de Creación de Compra a Meses (MSI)

```
┌─────────────────────────────────────────────────────────────────────────────────────┐
│                      COMPRA A MESES (MSI)                                            │
└─────────────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
┌─────────────────────────────────────────────────────────────────────────────────────┐
│  1. Usuario selecciona tarjeta de crédito                                            │
│     - Valida que sea tipo 'credit'                                                   │
│     - Verifica límite disponible                                                     │
└─────────────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
┌─────────────────────────────────────────────────────────────────────────────────────┐
│  2. Ingresa datos de la compra                                                       │
│     - Nombre, Monto total, Meses, Interés (opcional), Primer pago                   │
└─────────────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
┌─────────────────────────────────────────────────────────────────────────────────────┐
│  3. Backend procesa                                                                  │
│     - Calcula pago mensual (total / meses o con interés)                            │
│     - Crea deuda asociada                                                            │
│     - Crea N partialidades (una por mes)                                            │
│     - NO actualiza saldo de tarjeta                                                  │
└─────────────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
┌─────────────────────────────────────────────────────────────────────────────────────┐
│  4. Usuario paga partialidades mensualmente                                          │
│     - Selecciona cuenta origen (débito/efectivo)                                     │
│     - Se crea transacción de gasto                                                   │
│     - Se reduce saldo de tarjeta                                                     │
│     - Se reduce remaining_balance de la deuda                                        │
└─────────────────────────────────────────────────────────────────────────────────────┘
```
